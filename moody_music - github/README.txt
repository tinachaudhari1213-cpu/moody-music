
# Moody Music – A Mood-Based Music Application

## About
Moody Music is a mobile music application where users select their mood using emojis and discover related songs.

## Technologies Used
- Flutter and Dart
- Python Flask
- MySQL
- REST API

## Features
- User registration and login
- Emoji-based mood selection
- Music playback
- Search songs
- Favourites
- Recently played songs
- Offline music playback

## How to Run
1. Install Flutter and Python.
2. Install backend dependencies using:
   pip install -r requirements.txt
3. Start the Flask backend.
4. Run the Flutter application using:
   flutter pub get
   flutter run
